## 📖 About The Project

**Cafe Skylite** is a modern, visually stunning landing page for a premier rooftop lounge in Patna. Built with a focus on immersive user experience, it features state-of-the-art animations, a custom cursor, smooth scrolling, and dynamic interactions that reflect the premium dining experience of the lounge.

Whether you're craving Indian, Chinese, or Continental cuisine, Cafe Skylite promises an unforgettable time under the open sky.

---

## ✨ Features

- 🌓 **Dark & Light Mode Toggle:** Seamless theme switching for optimal viewing at any time of day.
- 🎨 **Immersive UI/UX:** A fully custom cursor and a stylish preloader to engage users instantly.
- 🚀 **GSAP Animations:** Smooth scroll-triggered animations and text effects powered by GreenSock.
- 💻 **Responsive Design:** A fully responsive layout that looks breathtaking on mobile, tablet, and desktop devices.
- 🎵 **Interactive Elements:** Ambient sound toggles and exciting confetti effects to celebrate reservations.
- 📝 **Dynamic Text Typing:** Beautifully animated headlines using Typed.js.

---

## 🛠️ Built With

This project is crafted using modern frontend technologies:

- **HTML5** for semantic structure.
- **CSS3** (Vanilla) for advanced styling, glassmorphism, and responsive grids.
- **JavaScript (ES6+)** for DOM manipulation and logic.
- **[GSAP (GreenSock)](https://gsap.com/)** & **ScrollTrigger** for high-performance animations.
- **[Typed.js](https://mattboldt.com/demos/typed-js/)** for typewriter text effects.
- **Canvas Confetti** for interactive visual effects.

## 🚀 Getting Started

To run this project locally and explore the code:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Aniketsingh-45/Website.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd Website/cafe
   ```
3. **Open the project:**
   Simply open `cafe.html` in any modern web browser.
   *(For the best development experience, use the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension in VS Code).*
