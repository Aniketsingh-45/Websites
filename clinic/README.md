## 📖 Overview

**Nath Aarogya Clinic** is an ultra-modern, responsive healthcare web platform engineered for Patna’s leading family medical center situated at **Saguna More, Danapur Main Road, Patna**. 

Designed with a **Cyber-Emerald Dark Mode** aesthetic, the platform combines clinical warmth with digital precision: GPU-accelerated HTML5 Canvas particle constellations, 3D cursor-reactive card tilts, client-side appointment validation, doctor credentials verification, and rapid 24/7 emergency care routing.

---

## ✨ Key Features

- 💎 **Cyber-Emerald Glassmorphism Dark UI**: Tailored visual identity featuring ambient glow orbs, multi-layered glass panels (`backdrop-filter: blur(16px)`), and high-contrast WCAG AAA compliant typography.
- 🌌 **GPU-Accelerated HTML5 Canvas Particle Network**: Lightweight constellation system with dynamic distance-based node connections that respond to window sizing without lag.
- ⚡ **GSAP 3 & ScrollTrigger Animations**: Silky smooth section entrances, staggered stat reveals, and magnetic micro-interactions.
- 🎛️ **3D Gyroscopic Perspective Tilt**: Interactive card tilt engine reacting to cursor velocity on physician credentials and diagnostic services.
- 📊 **Numerical Easing Counters**: Smooth IntersectionObserver counters showcasing 35+ years of excellence, 15,000+ patients healed, and 4.8⭐ verified Google rating.
- 📅 **Integrated OPD Appointment Booking**: Client-side validated form with real-time field checking, date pickers, department filters, and submission feedback.
- 🖼️ **Zero-Dependency Lightbox Gallery**: Custom modal lightbox with zoom previews, smooth fade animations, and keyboard navigation (`Esc`).
- 💬 **Patient Testimonials Slider**: Auto-advancing and touch-draggable review carousel highlighting authentic patient experiences.
- 🚨 **Rapid Emergency Action Bar**: Floating quick-action bar for direct **WhatsApp OPD Booking**, **Emergency Phone Call (+91 92881 90052)**, and Google Maps GPS navigation.

## 🎛️ Interactive Engine & UI Architecture

The JavaScript core (`script.js`) is organized into clean, modular lifecycle initializers:

```javascript
document.addEventListener('DOMContentLoaded', () => {
    initAmbientCanvas();      // HTML5 Canvas Floating Particle Constellation
    initNavigation();         // Mobile Drawer, Backdrop Blur & Sticky Observer
    initScrollAnimations();   // GSAP Choreographed Scroll Triggers
    init3DTilt();             // Gyroscopic Cursor Card Perspective Transformation
    initCounters();           // IntersectionObserver Animated Number Easing
    initGallery();            // Custom Zero-Dependency Lightbox Engine
    initReviewsSlider();      // Drag & Auto-sliding Testimonial Carousel
    initAppointmentForm();    // Live Validation & Form Submission Handling
    initScrollProgress();     // Circular SVG Scroll-Depth Tracker
});
```

## 🚀 Getting Started Locally

### 1. Clone the Monorepo
```bash
git clone https://github.com/Aniketsingh-45/Websites.git
cd Websites/clinic
```

### 2. Launch in Browser
Zero build steps or npm installations needed!
* **Option A**: Double-click `index.html` to open in your default browser.
* **Option B**: Run via Node.js serve:
  ```bash
  npx serve .
  ```
* **Option C**: Run via Python HTTP server:
  ```bash
  python -m http.server 8080
  # Open http://localhost:8080
  ```

## ☁️ Deploying to Vercel

The project is production-ready for [Vercel](https://vercel.com/):

### Option A: Via Websites Monorepo Dashboard
1. Go to [vercel.com/new](https://vercel.com/new) and select `Aniketsingh-45/Websites`.
2. Under **Root Directory**, click **Edit** and set to `clinic`.
3. Framework Preset: **Other**.
4. Click **Deploy**!

### Option B: Via Vercel CLI
```bash
cd clinic
npx vercel --prod
```
