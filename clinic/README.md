## 📖 Overview

**Nath Aarogya Clinic** is an ultra-modern, responsive web platform created for Patna’s leading family healthcare clinic located at Saguna More, Danapur. The website is engineered with a **Luxury Cyber-Emerald Dark UI** aesthetic, combining medical professionalism with seamless user interactions, high-performance animations, and effortless appointment scheduling.

Whether patients are seeking pediatric immunizations, gynecological consultations, diabetes management, or 24/7 emergency care, this portal provides instantaneous information, doctor credentials, customer testimonials, and direct emergency routing.

---

## ✨ Key Features

- 💎 **Luxury Glassmorphism & Cyber-Emerald Dark Mode**: Tailored visual identity featuring ambient glow orbs, multi-layered glass cards (`backdrop-filter`), and high-contrast accessible typography.
- 🌌 **Dynamic Ambient Canvas Particle System**: Lightweight, GPU-accelerated HTML5 Canvas particle background with proximity node connections.
- ⚡ **Choreographed GSAP & ScrollTrigger Animations**: Silky smooth reveals, cascading entrance transitions, and magnetic hover micro-interactions.
- 🎛️ **Interactive 3D Tilt Cards**: Perspective tilt engine for doctor profiles and specialty cards based on real-time cursor velocity.
- 📊 **Animated Stat Counters**: Smooth numerical easing counters showcasing 35+ years of excellence, 15,000+ happy patients, and 4.8⭐ Google rating.
- 📅 **Integrated Appointment Booking System**: Patient appointment form with real-time field validation, date pickers, department selection, and feedback states.
- 🖼️ **High-Performance Lightbox Media Gallery**: Zero-dependency modal lightbox with zoom preview, smooth modal animations, and keyboard navigation (`Esc`).
- 💬 **Patient Testimonials Carousel**: Auto-rotating and user-interactive testimonial slider with verified Google Reviews.
- 🚨 **Rapid Emergency Access Floating Bar**: Quick-action floating buttons for direct **WhatsApp Consultation**, **Instant Call routing (+91 92881 90052)**, and Google Maps directions.
- 📈 **Circular Scroll Progress & Smooth Back-to-Top**: SVG ring progress indicator dynamically reflecting page scroll depth.
- 📱 **100% Fluid Mobile-First Responsive Design**: Optimized across mobile screens, foldable displays, tablets, laptops, and ultra-wide desktop monitors.

## 🎛️ Interactive Engine & UI Architecture

The JavaScript core (`script.js`) is architected into modular lifecycle components:

```javascript
// Core Execution Pipeline
document.addEventListener('DOMContentLoaded', () => {
    initAmbientCanvas();      // HTML5 Canvas Floating Particle Node Network
    initNavigation();         // Mobile Drawer, Backdrop Blur & Sticky Observer
    initScrollAnimations();   // GSAP Choreographed Scroll Triggers
    init3DTilt();             // Gyroscopic Cursor Card Perspective Transformation
    initCounters();           // IntersectionObserver Animated Number Easing
    initGallery();            // Custom Zero-Dependency Lightbox Engine
    initReviewsSlider();      // Drag & Auto-sliding Testimonial Carousel
    initAppointmentForm();    // Live Validation & Form Submission Handling
    initScrollProgress();     // Circular SVG Scroll-Depth Tracker
});
```

## 🚀 Getting Started Locally

### 1. Prerequisites
No heavy build tools or runtime packages (`Node.js`/`npm`) are required to run this project. A modern web browser (Chrome, Firefox, Edge, Safari, Brave, Opera) is all you need.

### 2. Clone the Repository
```bash
# Clone the repository
git clone https://github.com/Aniketsingh-45/Website.git

# Navigate into the project directory
cd Website
```

### 3. Launch the Application
- **Option A (Direct)**: Double-click `index.html` or drag it into any web browser.
- **Option B (VS Code Live Server - Recommended)**:
  1. Open the project folder in VS Code.
  2. Right-click `index.html` and select **"Open with Live Server"**.
  3. The website will launch at `http://127.0.0.1:5500/index.html`.
- **Option C (Python Simple Server)**:
  ```bash
  python -m http.server 3000
  # Open http://localhost:3000 in your browser
  ```

## ⚡ Performance & UX Highlights

- 🏎️ **Zero External Framework Overhead**: Pure vanilla implementation guarantees instant page loads and sub-second Time to Interactive (TTI).
- 🎨 **GPU-Accelerated CSS Transitions**: All animations utilize `transform` and `opacity` properties to ensure a locked 60+ FPS rendering pipeline.
- 📱 **Touch-Friendly Target Sizes**: Designed to comply with WCAG 2.1 accessibility guidelines with minimum touch target areas (48x48px).
- 🔍 **SEO & Social Graph Ready**: Comprehensive `<meta>` tags, OpenGraph data, semantic heading levels (`h1`-`h4`), and descriptive `alt` tags.
