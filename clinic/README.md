# Nath Aarogya Clinic

Welcome to the website for **Nath Aarogya Clinic** — Patna's Trusted Family Healthcare center. Located at Saguna More, Danapur, Patna, the clinic is dedicated to compassionate, quality medical care for all age groups, focusing on preventive health, timely diagnosis, and personalized treatment under one roof.

## Features

- **Responsive Design**: A fully responsive website that looks great on desktops, tablets, and mobile devices.
- **Modern UI/UX**: Includes a modern, clean interface with animations, a sticky navigation bar, and floating action buttons for quick contact (WhatsApp and Call).
- **Sections**:
  - **Home (Hero)**: Eye-catching introductory section with quick actions.
  - **About Us**: Information about the clinic and its mission.
  - **Doctors**: Profiles of the expert medical professionals available.
  - **Specialties**: Overview of the specialized departments.
  - **Facilities**: List of key medical facilities provided (ECG, Pharmacy, Lab, etc.).
  - **Gallery**: A lightbox gallery showcasing the clinic's infrastructure.
  - **Reviews**: Patient testimonials carousel.
  - **Contact**: Location map, contact details, and an appointment booking form.

## Technologies Used

- HTML5
- CSS3 (with custom variables for theming, Flexbox/Grid for layout, and animations)
- Vanilla JavaScript (for interactivity like mobile menu, lightbox gallery, scroll animations, review slider, and counter animations)
- Google Fonts (Inter & Poppins)
- Font Awesome (for icons)

## Setup and Usage

To view the website, simply open `index.html` in any modern web browser. No build steps or server are required for local development.
