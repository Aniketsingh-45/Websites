# 🏥 Nath Aarogya Clinic

> **"Treatment That Heals Family"** 👨‍👩‍👧‍👦

Welcome to the official repository for the **Nath Aarogya Clinic** website — Patna's trusted family healthcare center. Located at Saguna More, Danapur, Patna, the clinic is dedicated to providing compassionate, high-quality, and complete medical care under one roof.

---

## 🌟 Key Features

*   **📱 Responsive & Fluid Design**: Fully optimized for desktops, tablets, and mobile screens.
*   **✨ Premium UI/UX**: Modern interface featuring smooth scroll animations, glassmorphism, and a sticky navigation system.
*   **⚡ Rapid Access Actions**: Integrated floating buttons for instant **WhatsApp** chat and **Direct Call** routing.
*   **🖼️ Interactive Media**: Rich gallery displaying clinic facilities with a custom-built, lightweight JavaScript lightbox.
*   **💬 Patient Testimonials**: Interactive user review carousel highlighting 4.8-star patient feedback.
*   **📅 Easy Appointments**: Embedded booking request form to seamlessly secure visit timings.

---

1.  **🏠 Hero Section**: Featuring dynamic rating highlights (4.8⭐ from 119+ Google Reviews) and immediate Call-to-Actions (CTAs).

---

## 🛠️ Technology Stack

*   **HTML5** - Structured semantic layout.
*   **CSS3** - Customized styling utilizing CSS variables, CSS grid/flexbox, and subtle keyframe micro-animations.
*   **JavaScript (Vanilla)** - Fast, dependency-free interactive elements (Lightbox, testimonial slider, counters).
*   **Fonts & Icons** - Google Fonts (Inter & Poppins) and Font Awesome 6 icons.

---

## 🚀 How to Run Locally

Since this is a lightweight static website, no configuration or build steps are necessary:

1.  Clone this repository or navigate to this folder.
2.  Open `index.html` in any web browser.
3.  *Optional*: Run with a local development server like VS Code's **Live Server** for the best experience.
