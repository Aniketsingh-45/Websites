# 🎁 Happy Birthday! Kiara ❤️✨

> A beautiful, interactive birthday surprise website designed with love. 🎉

This project is a dedicated, interactive web experience created as a special birthday gift. It features immersive animations, beautiful SVG decorations, background music, and a multi-screen interactive journey starting with a secret passcode.

---

## ✨ Features

- **Interactive Passcode Screen**: An engaging entry screen before the surprise is revealed.
- **Immersive Audio**: Plays a beautiful instrumental track to set the perfect mood.
- **Stunning Animations**: 
  - Canvas confetti bursts 🎊
  - Floating emojis and hearts ❤️
  - Animated SVG decorations (stars, diamonds, spirals) ✨
- **Image Gallery**: Beautifully presented photos.
- **Fully Responsive**: Designed to look perfect on any device, especially mobile.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure and multi-screen layout.
- **CSS3**: Advanced animations, variables, glowing effects, and responsive design.
- **Vanilla JavaScript**: Handles screen transitions, audio playback, and confetti logic.
- **External Libraries**: `canvas-confetti` for realistic confetti effects.

## 🚀 How to View

1. No installation required! This is a pure HTML/CSS/JS project.
2. Simply open `index.html` in any modern web browser.
3. Ensure your volume is turned up to enjoy the background music! 🎵
