## 📖 Overview

**Kiara Birthday Surprise** is a bespoke, interactive celebratory web experience crafted to deliver a memorable birthday experience. Engineered with modern HTML5, CSS3 animations, and vanilla JavaScript, it guides the recipient through a mystery security keypad gate into an emotionally resonant, musical celebration space complete with falling confetti, floating hearts, and a commemorative photo reel.

---

## ✨ Experience & Key Features

### 🔐 Interactive Passcode Unlock
- **3-Digit Mystery Lockbox**: An engaging entry screen greeting the visitor with a virtual glassmorphism keypad.
- **PIN Code**: Enter **`123`** on the onscreen dial pad (or use standard physical keyboard numbers).
- **Interactive Feedback**: Haptic vibration API triggers on mobile devices, accompanied by button bounce animations and instant verification checkmark (`✓ UNLOCKED!`).

### 🎵 Synchronized Soundtrack
- **Background Instrumental**: Automatically plays *"Surili Akhiyon Wale (Instrumental)"* upon unlocking.
- **Audio Control Floating Dock**: Recipient can toggle sound on/off or adjust playback at any time.

### 🎊 Dynamic Confetti & SVG Particles
- **Physics-Based Confetti**: Realistic particle explosions powered by `canvas-confetti` erupting across the screen.
- **Floating SVG Hearts & Stars**: Multi-layered ambient particles rising smoothly in the background.

### 📸 Memory Gallery Reel
- **Curated Photo Cards**: High-definition memories with soft polaroid borders, shadow depth, and celebratory wishes.
- **Fluid Touch Gestures**: Mobile-optimized touch scrolling and responsive layouts.

## 🛠️ Built With

- **HTML5**: Multi-screen semantic structure (`#screen-passcode`, `#screen-celebration`).
- **CSS3 (Vanilla)**: Glassmorphism (`backdrop-filter`), CSS variables, and fluid typography.
- **JavaScript (ES6+)**: Custom keypad input buffer, audio player coordinator, and confetti integration.
- **Canvas-Confetti**: High-performance HTML5 canvas particle engine.

## 🚀 Getting Started Locally

### 1. Clone the Monorepo
```bash
git clone https://github.com/Aniketsingh-45/Websites.git
cd Websites/gift
```

### 2. Open in Browser
No Node.js or build installation required:
- Simply double-click `index.html` in your favorite browser.
- **Important**: Make sure your device volume is turned up to enjoy the background soundtrack! 🎵
- Unlock code: **`123`**

---

## ☁️ Deploy to Vercel

### Option A: Via Websites Monorepo
1. In your [Vercel Dashboard](https://vercel.com/dashboard), click **Add New...** → **Project**.
2. Select your repository `Aniketsingh-45/Websites`.
3. Set **Root Directory** to `gift`.
4. Framework Preset: **Other**.
5. Click **Deploy**!

### Option B: Via Vercel CLI
```bash
cd gift
npx vercel --prod
```
