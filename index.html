Seamless Vercel Monorepo Deployment

Every project in this repository is equipped with its own production-grade vercel.json, clean URLs, security headers, and asset caching rules. You can deploy them in two ways:

01
Option A: Master Hub
Deploy the root repository without changing settings. The root vercel.json and this master showcase launchpad serve all 7 apps through unified routing.
02
Option B: Subproject Deploy
In Vercel project settings, set Root Directory to any folder (e.g. cafe, clinic, portfolio). Each folder is 100% self-contained.
03
Zero-Build Architecture
Static HTML/CSS/JS projects require no build commands. For dadan-handi, Vite automates npm run build into dist.
