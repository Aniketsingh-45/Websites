# Aniket Singh | Developer Portfolio

A modern, high-performance, dark-themed developer portfolio for **Aniket Singh** — B.Tech Computer Science student at RPSIT, Python specialist, AI/ML explorer, and full-stack developer.

## ✨ Features
- **Modern Dark Aesthetic**: Ambient glow lighting, subtle mesh grid, and cyber accents.
- **Glassmorphism & Spotlight Cards**: Mouse-following radial lighting effect on interactive cards.
- **Interactive Developer Shell**: Built-in interactive terminal supporting commands like `help`, `skills`, `projects`, `certs`, `contact`, `philosophy`, and `joke`.
- **Dynamic Typewriter Header**: Smoothly cycling developer titles and roles.
- **Filterable Projects Showcase**: Categorized tabs for AI/ML, Web & APIs, and Python utilities.
- **Verified Credentials Section**: Accredited coursework from Reliance Foundation, C-DAC, TCS iON, and Cisco Networking Academy.
- **GitHub Contribution Tracker**: Live integration of GitHub snake contribution animation and repository metrics.
- **Bento Grid Architecture**: Clean modular layout for academic journey, dev philosophy, and creative pursuits.
- **Interactive Contact Hub**: Direct copy-to-clipboard email action, social channels, and responsive form.

## 🛠️ Tech Stack
- **HTML5 & Vanilla CSS3**: High-performance, zero heavy runtime bloat.
- **Modern JavaScript (ES6+)**: Interactive DOM manipulation, IntersectionObserver scroll-reveal animations.
- **Google Fonts**: Outfit (Headings), Inter (Body), JetBrains Mono (Code/Badges).
- **Icons**: Font Awesome 6.
